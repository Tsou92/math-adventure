# 数学星球

面向家庭的儿童数学练习网站，支持加减法、乘法启蒙、乘法口诀、乘法后进退位加减和珠心算。线上地址：https://jisuan.tsounas.cn。

## 学习流程

- “乘法”分类下可选“乘法后加减”，例如 6×9＋28、6×9−28。乘数为 2～9，后接两位数进位加法或退位减法，结果不超过 100。每类最多 50 题，支持和其他题型混选。
- 孩子首页默认十道基础题，也可以展开自选知识点、题量和连算设置。选择会保存到账号。
- 轻松练习支持检查答案和两步提示；计时挑战在交卷后反馈。手机默认单题或连线小组，电脑默认整页，可随时切换。
- 普通输入支持 Enter 下一题、Shift+Enter 上一题。最后一题打开答题卡，仍需主动提交；有未答题时不能交卷。
- 答案批量自动保存，并在当前标签页保留临时草稿。网络失败可重试；多设备修改同一道题会要求选择保留的答案。重复交卷不会重复统计。
- 结果页右上角印章显示实际交卷日期与时间（北京时间，精确到秒），再次查看不会改变。可以复习本轮错题、相同设置再练或调整题目。错题复习记录保存在服务器；到期答对后依次安排 1、3、7 天后的复习，三次有效巩固标记掌握，答错重新巩固。
- 家长可查看每个孩子的知识点正确率、近期变化和练习记录，设置下一轮练习，并切换到孩子账号。返回家长管理需要重新登录。
- 新家长注册后获得一次性恢复码；已有家长可在“账号与安全”中验证密码后生成。恢复码仅显示一次，服务器仅保存哈希；使用后失效，并撤销旧登录会话。家庭设备记住的只有用户名。
- 旧版保存在浏览器的练习记录仍可从家长端查看，不会自动归入孩子账号。

## 技术结构

React 19 + TypeScript，Vercel 前端由 Vite 构建。`api/index.ts` 提供 Node API，数据库使用 Neon PostgreSQL 的 `kousuan` schema。页面按账号、家长、答题、复习与成绩拆分，家长和孩子端按需加载。URL hash 保存页面位置，不包含答案。

## 本地检查

需要 Node.js 22.13 或以上。通过环境变量或本机 `.env.local` 提供 `DATABASE_URL`，不要提交凭据。

```sh
npm install
npx tsc --noEmit --incremental false
npm test
npm run build:vercel
```

数据库集成测试会建立随机且独立的测试 schema，并在结束后删除。没有数据库连接时会跳过数据库测试。默认浏览器测试架不会启动服务。

需要检查完整本地页面和真实接口时，先构建，然后运行：

```sh
BROWSER_QA=1 npx vitest run server/browser-qa.test.ts --disableConsoleIntercept
```

服务仅监听本机 `http://localhost:4180`，使用独立测试数据。测试账号由测试架创建，详情见该文件。创建 `/tmp/math-adventure-qa-done` 文件后服务停止并清理测试 schema；下次运行前移除该标记。没有结束标记时最多运行 30 分钟。

## 数据库更新与发布

已有站点升级本次版本时，仅执行新增迁移，不需要重放旧迁移：

```sh
npm run db:migrate -- 005_multiply_mixed.sql
npm run build:vercel
npx --yes vercel@latest deploy --prod --yes --scope charmytsou-5522s-projects
```

每个迁移文件在一个事务内执行。005 新增默认值为 0 的新题型题量字段，并扩展题型和总题数约束，兼容旧练习数据；原账号、答题和成绩数据不会清空。未安装 004 的旧版本需先执行 004_learning_experience.sql。全新数据库可执行不带文件名的迁移命令。

发布使用已有 Vercel 项目 `kousuan-planet`，复用现有自定义域名。需验证生产部署 Ready、域名 HTTPS 返回 200、登录页实际渲染及接口可达。尚未产生新题型数据时可恢复上一 Vercel 部署；已有新题型数据后，回滚版本必须保留 multiplyMixed 枚举及其读写兼容，不能直接退回完全不认识新题型的版本。保留新增数据库结构和学习数据。
